# Security Policy

## Supported version
Please make sure your tine groupware is always up to date but report your vulnerability either way if it's in a recent
release or in a previous one.

## Version / Commit

Make sure you specify either the commit or the version (e.g. 2024.11.24) which is affected.

## Reporting a Vulnerability
Report vulnerabilities to:

*security@tine-groupware.de*

Please use pgp encryption for e-mail communication with our security-team.\
